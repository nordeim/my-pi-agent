# Palette Presets — 8 Curated Palettes

> Each palette is a coherent (background + primary + accent) trio tuned for a specific use case. Pick one, or use as inspiration for a custom palette.

---

## 1. GitHub Dark (default for dev-tool decks)

```css
--bg: #0D1117;
--bg-elevated: #161B22;
--bg-surface: #1C2128;
--border: #30363D;
--border-muted: #21262D;
--primary: #E6EDF3;
--primary-muted: #8B949E;
--primary-subtle: #6E7681;
--accent: #58A6FF;
--accent-soft: rgba(88, 166, 255, 0.12);
--accent-glow: rgba(88, 166, 255, 0.25);
```

**Use case:** Dev-tool repos, GitHub-integrated products, developer-facing marketing.
**Visual reference:** Linear changelog, GitHub Dark Default theme.
**Tonal feel:** Native to developers. Blue accent on near-black background.
**Recommended default** for most dev-tool decks.

## Custom palette rules

If none of the presets fit, design a custom palette:

1. **Background:** Dark palettes — pick a near-black with a slight hue tint (e.g., `#0D1117` has a blue tint). Never pure `#000000` unless going for Vercel Monochrome.
2. **Primary text:** Off-white, not pure white (e.g., `#E6EDF3`, `#FAFAFA`). Pure white on dark backgrounds causes eye strain.
3. **Accent:** One color only. Test contrast against the background — must pass WCAG AA (4.5:1 minimum for text, 3:1 for large text and UI components).
4. **Tonal stops:** Always define `--bg-elevated`, `--bg-surface`, `--border`, `--border-muted`, `--primary-muted`, `--primary-subtle`. Sub-agents need these for card surfaces and hierarchy.
5. **Accent-soft and accent-glow:** Use `rgba()` with the accent's RGB values at 0.12 and 0.25 alpha respectively.

## Anti-patterns

### Anti-pattern: pure black background (`#000000`) with a colored accent
Pure black causes eye strain on long viewing. Use a near-black with a slight hue tint (e.g., `#0D1117`, `#0A0E14`, `#0F1F14`).

### Anti-pattern: pure white text (`#FFFFFF`) on dark background
Use off-white (e.g., `#E6EDF3`, `#FAFAFA`). Pure white is too harsh.

### Anti-pattern: multiple accent colors
One accent only. If you need a "success" or "warning" color, define them as separate tokens (`--success`, `--warning`) but use them sparingly — never as a second accent.

### Anti-pattern: low-contrast accent on background
Test the accent against the background. If the contrast ratio is below 3:1, the accent is invisible. Use a lighter or darker shade.
