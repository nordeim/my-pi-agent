# Executive Deck Skill Suite — Archive Manifest

This archive bundles the `building-executive-decks` skill together with the two
parent skills it was derived from, plus its validation demo and diagnostic
tooling. Everything an AI coding agent needs to install, audit, or extend the
skill lineage is included.

## Contents

| Path                        | What it is                                                                 |
|-----------------------------|----------------------------------------------------------------------------|
| `skills/executive-strategy-deck/` | **The new skill** (`building-executive-decks` v1.0.0): 5-phase workflow, 10 page archetypes, locked design tokens, chart recipes, QA gates |
| `skills/pptx/`              | **Parent skill — PPT domain**: .pptx creation/editing, ooxml pack/unpack/validation tooling, style extractors |
| `skills/skill-creator/`     | **Parent skill — skill authoring**: Anthropic Agent Skills spec, packaging, validation, eval/benchmark harness |
| `demo/`                     | Validation deck rendered purely from the new skill's files: `deck.json` manifest + 10 standalone 1280×720 HTML slides (illustrative "Atlas AI 2026" data) |
| `tools/probe_depth.js`      | Playwright headless probe that reports the deepest-reaching elements of a slide — the diagnostic behind the 720px geometry gate |
| `SHA256SUMS`                | SHA-256 checksums of every file in this archive (except itself and this manifest) |

## Skill lineage

```
skills/skill-creator/  (spec: name/description budgets, reference layering, evals)
skills/pptx/           (domain: slide rendering, HTML→PPTX, OOXML tooling)
        │
        └──────────►  skills/executive-strategy-deck/   (new, self-contained)
                              │
                              └──► demo/  (rendered by agents using only the skill files)
```

- `skill-creator` supplied the Anthropic Agent Skills compliance rules (frontmatter
  budgets, one-level references, eval-driven iteration).
- `pptx` supplied presentation-domain knowledge and the HTML-rendering toolchain
  conventions the new skill builds on.
- The new skill is **standalone**: it does not import from either parent at
  runtime; parents are included for provenance, extension, and cross-checking.

## Inside the new skill (`skills/executive-strategy-deck/`)

```
SKILL.md                        5-phase workflow + 10 hard quality rules

scripts/geometry_check.js       Playwright overflow audit (hard 720px limit)

```

## Installing the new skill

Copy (or unzip) `skills/executive-strategy-deck/` into your agent's skills
directory, e.g. `.claude/skills/executive-strategy-deck/` or the equivalent
for your runtime. The parent skills are optional at runtime and included for
reference only.

## Verifying integrity

```bash
sha256sum -c SHA256SUMS
```

## Notes

- The standalone `executive-strategy-deck.zip` deliverable is intentionally NOT
