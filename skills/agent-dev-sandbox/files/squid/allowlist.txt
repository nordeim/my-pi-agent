# Matching rules (Squid dstdomain — verified against Squid's own docs;
# audit H-4: the old comment was wrong):
#   * ".githubusercontent.com"  (LEADING DOT) matches every subdomain
#   * "github.com" (bare) matches ONLY github.com, exactly — subdomains
#     must be listed individually or covered by a leading-dot entry
#   * "*.example.com" is NOT a wildcard — Squid treats it as a literal
#     hostname that matches nothing. 30-gateway.sh allow rejects it.
# Squid (dstdomain) resolves DNS itself — workspaces never need external DNS.
# NOTE (Squid): do not list a subdomain (a.example.com) before its
# leading-dot entry (.example.com) in this file — Squid treats that as a
# fatal configuration error at parse time.
